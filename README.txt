MY SALAH — 30 DAYS (PWA)

FILES
- index.html: app
- manifest.json: install name, colors and icons
- sw.js: offline cache
- icons/: app icons

PUBLISH WITH GITHUB PAGES
1. Sign in to GitHub and create a new public repository, e.g. my-salah.
2. Upload all files and the icons folder from this package. Keep index.html at the repository root.
3. In the repository open Settings -> Pages.
4. Under Build and deployment choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to publish and open the HTTPS address it provides.

INSTALL
- Android: open the HTTPS site in Chrome, tap the three-dot menu, then Install app (or Add to Home screen).
- iPhone: open the HTTPS site in Safari, tap Share, then Add to Home Screen.

NOTES
- The app stores prayer checkmarks in this browser/device's localStorage.
- Do not clear the browser's site data if you want to keep the marks.
- Export/backup and sync between devices are not included in this first PWA package.
